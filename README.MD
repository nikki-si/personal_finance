# Система управления личными финансами

## Назначение
Приложение для учёта личных расходов и контроля бюджета. Консольная версия (ПР3) дополнена веб-интерфейсом на Django (ПР5) и переведена на систему шаблонов (ПР6).

## Используемые технологии
- Python 3
- Django 5.2
- Django Template Language (DTL)
- HTML5, CSS3, JavaScript
- Bootstrap 5.3
- JSON (хранение данных)
- pytest, flake8

## Предметная область
Учёт финансовых операций (расходов). Каждая транзакция имеет сумму, категорию и описание.

## Основные сущности
- **Transaction** — отдельная финансовая операция (расход): `id`, `amount`, `category`, `description`.

## Страницы веб-интерфейса
- `/` — главная (описание и навигация)
- `/transactions/` — список всех транзакций
- `/transactions/<id>/` — карточка отдельной транзакции
- `/stats/` — статистика по категориям
