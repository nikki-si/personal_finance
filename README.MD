# Система управления личными финансами

## Назначение
Приложение для учёта личных расходов и контроля бюджета.

## Целевая аудитория
Люди, которые хотят отслеживать свои траты и не выходить за рамки месячного бюджета.

## Предметная область
Учёт финансовых операций (расходов). Каждая операция имеет сумму, категорию и описание. 
Система позволяет добавлять траты, просматривать их список и подсчитывать общую сумму расходов.

## Основные сущности
- Транзакция (Transaction) — отдельная финансовая операция (расход).

## Основные функции
- Добавление новой транзакции (расхода).
- Просмотр списка всех транзакций.
- Подсчёт общей суммы расходов.
- Сохранение данных в файл и загрузка при следующем запуске.

## План развития
На следующих этапах планируется:
